Privacy Policy

Hermes Personal Assistant · Effective November 10, 2026

Who uses this app

Hermes is a private tool used only by its owner, on the owner's own computer, with the owner's own Google accounts. It is not a public service and collects no data from anyone else.

Google data the app accesses

  • Gmail (gmail.modify): read and search messages, and archive or un-archive messages at the owner's request. The app has no feature to send, trash, or delete email.
  • Google Calendar (calendar.readonly, calendar.events): read events and add events at the owner's request. The app has no feature to edit or delete events.

How the data is used

Only to answer the owner's own questions (for example "what's on my calendar this week") and to carry out the owner's own requests (for example "archive promotional email"). Data is not used for advertising, profiling, or training AI models.

Storage and sharing

  • Sign-in tokens are stored only on the owner's computer, in a file readable only by the owner.
  • Email and calendar content is processed on that same computer by a locally run AI model.
  • Answers (for example a short email summary) are delivered only to the owner, in the owner's own Hermes app or the owner's own private Telegram chat.
  • No Google user data is sold, shared, or transferred to any third party.

Google API Services User Data Policy

Hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/connections. Deleting the token files on the owner's computer also removes all access.

Contact

Questions can be sent through the GitHub account that hosts this page.
